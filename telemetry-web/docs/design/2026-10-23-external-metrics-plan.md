# telemetry-web ExternalMetrics Implementation Plan

> Superseded in review (#33): handlers now follow the global MeterProvider, `Init` checks `OTLPEndpoint`, and `ExternalMetrics` became `Config.MeterProvider`; the spec is current.

**Goal:** Add `Config.ExternalMetrics` so a service can leave the global
meter provider to another component and use telemetry-web for tracing and
HTTP instrumentation only.

**Architecture:** `Init` skips building, installing and retiring a meter
provider when the switch is set, and skips the Go runtime metrics. The
`nethttp` and `endpoint` packages are unchanged: they already read the
global provider, which the other component owns.

**Tech Stack:** Go 1.25 module `github.com/stakater/operator-utils/telemetry-web`,
OpenTelemetry Go SDK, standard `testing` package.

**Spec:** `telemetry-web/docs/design/2026-10-23-external-metrics.md`

## Global Constraints

- Work in `/workspaces/cloud-orchestrator/operator-utils`, branch
  `feat/telemetry-web-external-metrics` (exists, holds the spec).
- The zero value of `ExternalMetrics` keeps today's behaviour exactly;
  every existing test passes unchanged.
- In the new mode, never call `otel.SetMeterProvider`, not at start, not on
  shutdown, not on failure.
- No environment variable for the switch. No early endpoint validation.
- Tests use the standard `testing` package, like the rest of the module.
- Checks CI runs, all from `telemetry-web/`: `go mod tidy -diff`,
  `go build ./... && go vet ./...`, `go test -race -count=1 -shuffle=on ./...`,
  `golangci-lint run ./...` (uses `telemetry-web/.golangci.yml`; CI pins

package telemetry

import (
	"context"
	"net/http"
	"net/http/httptest"
	"strings"
	"testing"

	"go.opentelemetry.io/otel"
	"go.opentelemetry.io/otel/metric"
	sdkmetric "go.opentelemetry.io/otel/sdk/metric"
	"go.opentelemetry.io/otel/sdk/metric/metricdata"

	"github.com/stakater/operator-utils/telemetry-web/endpoint"
	"github.com/stakater/operator-utils/telemetry-web/nethttp"
)

// ownMeterProvider installs a provider standing in for the component that
// owns metrics when ExternalMetrics is set, such as observability's
// Publisher, and restores the previous global afterwards.
func ownMeterProvider(t *testing.T) (*sdkmetric.MeterProvider, *sdkmetric.ManualReader) {
	t.Helper()
	reader := sdkmetric.NewManualReader()
	mp := sdkmetric.NewMeterProvider(sdkmetric.WithReader(reader))
	prev := otel.GetMeterProvider()
	otel.SetMeterProvider(mp)
	t.Cleanup(func() { otel.SetMeterProvider(prev) })
	return mp, reader
}

func initExternal(t *testing.T) func(context.Context) error {
	t.Helper()
	shutdown, err := Init(context.Background(), Config{
		ServiceName:     "test-svc",
		Insecure:        true,
		ExternalMetrics: true,
	})
	if err != nil {
		t.Fatalf("Init returned error: %v", err)
	}
	return shutdown
}

func metricNames(t *testing.T, r *sdkmetric.ManualReader) map[string]bool {
	t.Helper()
	var rm metricdata.ResourceMetrics
	if err := r.Collect(context.Background(), &rm); err != nil {
		t.Fatalf("collect: %v", err)
	}
	names := map[string]bool{}
	for _, sm := range rm.ScopeMetrics {
		for _, m := range sm.Metrics {
			names[m.Name] = true
		}
	}
	return names
}

func TestExternalMetrics_InitKeepsTheCallersMeterProvider(t *testing.T) {
	mp, _ := ownMeterProvider(t)
	shutdown := initExternal(t)
	defer func() { _ = shutdown(bounded(t)) }()

	if got := otel.GetMeterProvider(); got != metric.MeterProvider(mp) {
		t.Errorf("global MeterProvider is %T after Init, want the caller's", got)
	}
}

func TestExternalMetrics_ShutdownLeavesTheCallersMeterProvider(t *testing.T) {
	mp, _ := ownMeterProvider(t)
	shutdown := initExternal(t)
	_ = shutdown(bounded(t))

	if got := otel.GetMeterProvider(); got != metric.MeterProvider(mp) {
		t.Errorf("global MeterProvider is %T after shutdown, want the caller's", got)
	}
	if !isNoopTracerProvider(otel.GetTracerProvider()) {
		t.Errorf("global TracerProvider is %T after shutdown, want the noop", otel.GetTracerProvider())
	}
}

// In this mode Init has no reachable failure after it starts changing
// global state (the trace exporter validates its endpoint lazily), so the
// failure path's reset is tested on retire itself.
func TestRetireLeavesAMeterProviderItDoesNotOwn(t *testing.T) {
	mp, _ := ownMeterProvider(t)

	retire(false)

	if got := otel.GetMeterProvider(); got != metric.MeterProvider(mp) {
		t.Errorf("global MeterProvider is %T after retire(false), want the caller's", got)
	}
	if !isNoopTracerProvider(otel.GetTracerProvider()) {
		t.Errorf("global TracerProvider is %T after retire(false), want the noop", otel.GetTracerProvider())
	}
}

func TestExternalMetrics_InstrumentationRecordsIntoTheCallersProvider(t *testing.T) {
	_, reader := ownMeterProvider(t)
	shutdown := initExternal(t)
	defer func() { _ = shutdown(bounded(t)) }()

	h := nethttp.Handler(http.HandlerFunc(func(_ http.ResponseWriter, r *http.Request) {
		endpoint.Instrument(r.Context(), "probe")(nil)
	}))
	h.ServeHTTP(httptest.NewRecorder(), httptest.NewRequest(http.MethodGet, "/probe", nil))

	names := metricNames(t, reader)
	for _, want := range []string{"http.server.request.duration", "endpoint.duration"} {
		if !names[want] {
			t.Errorf("caller's provider has no %s; got %v", want, names)
		}
	}
	for name := range names {
		if strings.HasPrefix(name, "go.") {
			t.Errorf("telemetry-web started runtime metric %s on the caller's provider", name)
		}
	}
}

```go
// startMetrics builds the meter provider, makes it the global one and
// starts the Go runtime metrics on it. With ExternalMetrics another
// component owns metrics, so it does nothing and returns nil.
func startMetrics(ctx context.Context, cfg Config, res *resource.Resource) (*sdkmetric.MeterProvider, error) {
	if cfg.ExternalMetrics {
		return nil, nil
	}
	reader, err := newMetricReader(ctx, cfg)
	if err != nil {
		return nil, err
	}
	mp := sdkmetric.NewMeterProvider(
		sdkmetric.WithReader(reader),
		sdkmetric.WithResource(res),
	)
	otel.SetMeterProvider(mp)

	// Bound to mp rather than the global provider so mp.Shutdown retires the
	// runtime callbacks along with it.
	if err := runtime.Start(runtime.WithMeterProvider(mp)); err != nil {
		_ = mp.Shutdown(context.WithoutCancel(ctx))
		return nil, err
	}
	return mp, nil
}
```

Replace `retire` with:

```go
// retire points the global providers at noops, so a lingering goroutine writes
// into a noop rather than a dead pipeline. Cached instruments follow on their own,
// because they compare the global provider on each use. The meter provider is
// reset only when Init owned it: with ExternalMetrics it belongs to another
// component, which keeps exporting after tracing stops.
//
// It deliberately does NOT restore the propagator or the error handler. Neither
// holds a pipeline, so neither can write anywhere after shutdown; the propagator
// in particular is better left installed, since a straggler outbound call still
// emits a well formed traceparent instead of silently dropping context. Undoing
// them would mean stashing the pre-Init error handler in package state, which is
// more machinery than the problem justifies.
func retire(ownsMetrics bool) {
	otel.SetTracerProvider(tracenoop.NewTracerProvider())
	if ownsMetrics {
		otel.SetMeterProvider(metricnoop.NewMeterProvider())
	}
	ident.SetServiceName("")
}
```

Add a subsection at the end of `## Configuration`:

````markdown
### Metrics owned by another component

An operator that serves its metrics on controller-runtime's `/metrics`
through the `observability` module's `Publisher` can still use
telemetry-web for tracing and HTTP instrumentation. Create the `Publisher`
first, then call `Init` with `ExternalMetrics`:

```go
pub, err := publisher.New(ctx, publisher.Config{OperatorName: "my-operator"})
// handle err
shutdown, err := telemetry.Init(ctx, telemetry.Config{
    ServiceName:     "my-operator",
    ExternalMetrics: true,
})
```

`Init` then builds no meter provider, starts no Go runtime metrics, and
never sets or resets the global MeterProvider; shutdown flushes traces
only. The HTTP and `endpoint` metrics record into the `Publisher`'s
provider, so build handlers after both calls: `otelhttp` reads the global
provider once, when the handler is built.

In this mode a malformed OTLP endpoint does not make `Init` fail. The
trace exporter checks it lazily, so the error shows up through the error
handler in the log when spans are exported.
````

## What

`Config.ExternalMetrics`: when set, `Init` sets up tracing only. It builds
no meter provider, starts no Go runtime metrics, and never sets or resets

into whatever provider is global, which another component owns.

## Why

An operator that is also a web server (cloud-orchestrator-gateway) wants
its metrics on controller-runtime's `/metrics`, always on, through
`observability`'s `Publisher` (#28), and telemetry-web's traces and HTTP
instrumentation. Today `Init` replaces the `Publisher`'s provider with an
OTLP-only one, starts the runtime metrics a second time, and resets the
global provider to a no-op on shutdown.

## Worth knowing

- Opt in: the zero value keeps today's behaviour, so finops-gateway is
  unaffected.
- No environment variable: `OTEL_METRICS_EXPORTER=none` would mean "no
  metrics at all", the opposite of this mode.
- In this mode a malformed OTLP endpoint no longer fails `Init`; the trace
  exporter reports it when exporting. Documented.
- Design: `telemetry-web/docs/design/2026-10-23-external-metrics.md`.
EOF
